# Лабораторная работа № 10

Лендинг на Bootstrap 5.

Сайт компании «Food Construct» — доставка бизнес-ланчей.

## Запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python -m http.server 8080
```

Лабораторные 7–10 используют API и `localStorage`, поэтому их лучше открывать через локальный сервер, а не по `file://`.
